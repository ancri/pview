    pview keys

    j / knext / previous entry (arrows work too)
    g / Gfirst / last entry
    l / Enteropen the folder, or on a file, go to the folder it lives in
    h / Backspaceparent folder
    /filter the list (Enter keeps it, Esc clears)
    ralso list images from subfolders (folders stay listed either way)
    ssort by time or by name
    wheel / pinchzoom at the pointer
    dragmove the image
    double clickzoom in at that spot, again to fit
    + / - / 0 / 1zoom in, out, fit, actual size
    wfit width instead of whole image
    H J K Lmove the image with the keyboard
    o / yopen image in a new tab / copy its path
    Escclear the filter, else reset zoom
